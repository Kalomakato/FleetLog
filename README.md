# FleetLog

FleetLog is a web application for municipalities and enterprises in Bulgaria to manage their company vehicles. It will track vehicle details, mileage in kilometres, refuelling, repairs and associated costs.

The application is currently in development. The basic ASP.NET Core MVC starter application is working; fleet management features will be added throughout October.

## Български — Автопарк

Автопарк е уеб приложение за общини и предприятия, което помага за управлението на служебните автомобили. То ще следи данни за автомобилите, километраж, зареждания, ремонти и свързаните с тях разходи.

Приложението все още се разработва. В момента работи само началното ASP.NET Core MVC приложение. Функциите ще бъдат добавяни през октомври.
